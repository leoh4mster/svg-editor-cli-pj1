## 已确认的实现方向

- 使用 TypeScript、面向对象、字段封装和一类一文件。
- Command 是必需模式。CLI 的注册表根据命令名取得命令对象，命令通过统一入口执行。
- 领域模型不依赖终端、文件系统或 XML 库。应用层不依赖 CLI 或基础设施的具体实现。
- 第 2 阶段引入 Composite 的统一子节点、摘要、属性和遍历接口；第 3 阶段增加递归编辑语义，第 4 阶段实现层级与顺序调整。
- 图形类型只在图形工厂分派，命令名只在命令注册表分派；这两处按题目要求标注“待重构”。
- 第 3 阶段采用文档快照支持历史。图形通过多态返回独立副本，编辑会话在草稿上执行，成功后才切换当前文档及更新历史；先保证嵌套结构、节点顺序和删除内容能够准确恢复。每个历史项保存两份完整文档，空间成本随文档大小线性增长。
- 第 4 阶段五条结构命令沿用 `EditCommand`，结构操作由领域文档负责；先完整校验，再以多态重建独立森林和局部文档，全部成功后原子接管结构及索引，不绕过归属保护。
- 第 5 阶段由 `TextFileStore` 和 `SvgCodec` 端口隔离文件系统与 XML。基础设施实现严格 UTF-8 文件读写、同目录临时文件加重命名和 XML 转换；读取全部成功后提交文档，保存成功后才更新路径和历史。
- SVG 构造与 CLI 创建共用原图形工厂的类型配方，输出使用图形的结构化属性、文本和子节点多态接口；保留额外属性及根元数据，不增加类型名分派。
- `box` 及插件加载留给后续课程阶段，本次不实现。

## 第 1 阶段的接口约定

- `init` 默认 800×600；只给宽度时高度为 600；最多两个尺寸参数。
- `canvas` 无参数查询；两个参数修改；只给一个参数报错。
- 尺寸必须为有限正数。修改前完成全部校验，失败不改变当前文档。
- 参数解析支持双引号、引号和反斜杠转义；仅整行注释，参数中的 `#ffffff` 不被截断。
- 交互终端显示 `svg>`；管道输入不显示提示符；单条命令报错后继续处理下一行。
- 显示帮助不需要先初始化文档；需要文档的命令在未初始化时使用题目规定的错误信息。

## 第 2 阶段的接口约定

- `create` 提供六种内置类型，尾部支持 `in <containerId>`；必须先有文档及目标容器。
- ID 全文档唯一、大小写敏感，允许中文；禁止空值、空白和 C0 / DEL 控制字符。创建前验证整个候选子树，不允许部分挂接或只登记部分索引。
- 坐标可以为负数；所有数值必须有限；图形宽高、半径允许零，不允许负数；画布宽高仍必须为正数。
- 可选 `fill` / `stroke` 省略时不补写默认属性。文本保留中文、空格、引号和反斜杠。
- `tree` 显示画布及有序结构，内联几何摘要；`tree <id>` 只显示子树；`show <id>` 显示完整属性和父级。
- 文档持有根节点、全局 ID 与父级索引，负责挂接；图形子节点返回快照。已挂接图形具有文档归属，容器只接受持有文档私有令牌的结构修改，不能跨文档共享节点。格式化器只生成文本，不接触 CLI IO，也不按类型分派。
- 图形工厂在应用层转换参数；几何验证在领域层。`main.ts` 组装创建命令、工厂与格式化器。

## 第 3 阶段的接口约定

- `move` 接受有限增量；`scale` 只接受有限正倍数，同时缩放位置和尺寸，容器递归作用于子孙；不缩放 `stroke-width`，也不修改文本内容。
- `set` 的通用白名单为 `fill`、`stroke`、`stroke-width`，各类型再负责自身几何属性，文本另支持 `text`；白名单外统一报 `unknown attribute: <attr>`。尺寸、半径、描边宽度允许零但不允许负数。数值解析由领域 `NumericValue` 统一处理，应用层 `CommandArguments` 委托它，不产生领域到应用层的依赖。
- `set` 修改 `g` 的样式是设置该容器的属性，采用标准 SVG 继承语义，不覆盖子节点显式样式；`delete` 删除容器及全部子孙。
- `Shape.clone/moved/scaled/withAttribute` 返回独立、未归属的深拷贝。`SvgDocument` 的受控替换保留原父级及同级位置，并维护 ID、父级索引和归属；删除前完成校验。克隆通过多态创建图形，不增加按类型分派或字符串序列化。
- `EditCommand` 继承 `Command`，将成功编辑统一交给 `EditorSession.executeEdit`。会话先克隆草稿，在草稿上执行编辑，再复制提交结果并准备历史快照，全部成功后再提交当前文档和历史；即使递归编辑在后续子孙处溢出，原文档与历史也不改变。提交结果与回调草稿也相互隔离。
- 历史由 `application/history` 的 `HistoryEntry`、`CommandHistory` 管理；每个编辑保存执行前后快照，恢复时再克隆，禁止共享可变历史引用。`create` 也进入同一历史路径；`help/tree/show` 不记录历史。
- `undo` / `redo` 成功摘要以 `undone: ...` / `redone: ...` 表示原编辑；没有相应历史时分别报 `nothing to undo` / `nothing to redo`。撤销后只有成功的新编辑清空 redo，失败编辑和显示命令均保留分支。
- 成功 `init` 或修改 `canvas` 后清空两栈并禁用历史；此时两条命令均按题目原文报 `undo not allowed after io command`，直到下一次成功编辑。`canvas` 查询、失败的文档命令与显示命令不影响该状态。`read/save` 在第 5 阶段接入同一规则。

## 第 4 阶段的接口约定

- `group <newGid> <id1> <id2>…` 至少选择两个不同的已有 ID，新 ID 必须合法且全局唯一；同时选择祖先与后代时报 `cannot group a container into its own descendant: <祖先id>`。
- 所选节点按操作前文档前序遍历排列，不采用命令参数顺序。新组父级取所选节点原父级的最近公共祖先，跨根时取画布；插入到最早受影响的该父级直属子节点位置。同父级时即最早被选节点位置；其他节点相对顺序不变，搬空的旧容器保留。
- `ungroup` 仅解散嵌套容器，子节点按原顺序替换容器原位置；空容器直接移除。根级容器报题目规定的 `cannot ungroup top-level container: <id>`，叶子报 `not a container: <id>`。
- `addto <gid> <id>` 将节点连同子树移到目标末尾，原本已属于目标时也移到末尾；目标缺失或为叶子与 `create ... in` 使用同样错误；拒绝自身归属及移入自身后代。
- `front` 将节点移到同级末尾，对应 SVG 后绘制、在上层；`back` 移到同级开头。二者不改变父级，根级和嵌套节点均适用。
- 结构编辑保留图形自身的几何属性和显式样式，不固化继承值。改换父级可能改变继承样式，解组移除原容器自己的样式；不增加坐标变换或隐式属性。
- 五条结构命令继承 `EditCommand`，不新增历史机制；成功命令整体为一个撤销单元，合法无变化操作也记录；失败保留文档和全部历史状态。
- `Shape.withChildren` / `Group` 的多态容器重建不按类型名分派；领域结构操作在局部 `SvgDocument` 完成完整森林、全局 ID、父级索引与归属重建后才接管状态，直接领域 API 失败也不改变原文档。新树不复用已归属节点，成功后应按 ID 重新取节点引用。

## 第 5 阶段的接口约定

- `read <file.svg>` 无须先初始化，完整读取及验证成功后替换当前文档；`save [file.svg]` 必须已有文档。成功摘要的元素数包括容器，排除根 `svg`。
- 会话记住最近成功 `read/save` 的路径；无参数 `save` 使用该路径，尚无路径时报错。成功 `init` 清空路径；画布修改、编辑及 undo/redo 不改路径。相对路径相对于程序工作目录，含空格路径用双引号。
- 成功 `read/save` 清空并禁用历史，直到下一次成功编辑。文件读取、XML 解码、SVG 编码或文件写入失败，均保留当前文档、路径、redo 分支及历史禁用状态；补 ID 警告仅在读取提交成功后输出。
- `TextFileStore` 和 `SvgCodec` 位于应用端口；`NodeFileStore` 严格解码 UTF-8，写入采用目标同目录临时文件、完整写入及重命名替换，保留普通文件权限与符号链接引用，清理失败临时文件。`SvgReadResult` 封装文档与警告。
- XML 解析和名称校验使用固定版本 `saxes 6.0.0`、`xmlchars 2.2.0`，仅基础设施导入这些库。第三方声明与 TypeScript 5.9 严格可选属性存在兼容问题，因此开启 `skipLibCheck`；源码及测试仍启用严格类型检查。
- 读取 XML 1.0、六种内置图形及嵌套 `g`。先预扫描全部非空显式 ID，再按文档顺序为缺失或空 ID 图形补 `类型名+序号`，避免与后文 ID 冲突；根 ID 同样保留并预留，根不作为可编辑图形。
- 几何长度接受数字和可选 `px`，缺省图形几何值为零；根尺寸缺省时取 `viewBox`，否则取 800×600。导入 `viewBox` 保留到画布修改，届时重设为 `0 0 宽 高`。
- 图形工厂通过同一配方查找实现 `create/fromSvg`；输出通过图形统一的 `svgAttributes/textContent/children/isContainer`，不在 XML 适配器新增类型名分派。规范几何和样式属性不能由额外属性覆盖。
- 显式样式、根元数据、字体、对齐、`data-*` 与合法前缀属性等额外内容随图形克隆、变换、结构调整及历史保留；导入时为使用前缀的属性就地保留所需命名空间绑定，防止移出原容器或解组后前缀失效。额外属性不扩大 `set` 白名单。
- XML 特殊字符、属性引号和需要保留的换行正确转义。纯文本实体和 CDATA 可读；注释、原始缩进、属性顺序、前缀化元素写法及实体原写法不作逐字保留。
- 未知标签、外部元素命名空间、复杂文本子元素、坐标列表、百分比及其他长度单位、`transform/style/href/on*`、DOCTYPE、处理指令不在支持范围，读取明确报错，不静默丢弃语义。
